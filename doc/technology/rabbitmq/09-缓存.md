# 身份验证/授权缓存后端

## 概述

此插件提供了一种为身份验证和授权后端结果设置可配置缓存时间的方法。它不是一个独立的身份验证后端，而是现有后端（如内置后端、LDAP 或 HTTP 后端）的缓存层。虽然它对于内置（内部）身份验证和授权后端的作用不大，但对于使用网络请求的其他后端（如 LDAP 或 HTTP）非常有用。

目前缓存过期是基于时间的。

## 安装

`rabbitmq_auth_backend_cache` 插件随 RabbitMQ 一起提供。

与所有插件一样，它必须先启用才能使用，例如，使用 `rabbitmqctl`
    
    
    rabbitmq-plugins enable rabbitmq_auth_backend_cache  
    

## 授权和身份验证后端配置

要配置此插件以缓存所有授权和身份验证决策，请首先将此缓存后端设置为 `auth_backends`（或其中之一），然后配置实际要缓存的身份验证后端。

例如，缓存对 `http` 后端的请求：
    
    
    auth_backends.1 = cache  
    
    
    auth_cache.cached_backend = http  
    
    
      
    
    
    auth_http.http_method = post  
    

可以为授权和身份验证使用不同的后端。

以下示例将插件配置为使用 LDAP 后端进行身份验证，但使用内部后端进行授权：
    
    
    auth_backends.1 = cache  
    
    
      
    
    
    auth_cache.cached_backend.authn = ldap  
    
    
    auth_cache.cached_backend.authz = internal  
    

## 基本缓存配置

您可以使用 `cache_ttl` 配置变量（以毫秒为单位）来配置缓存条目的 TTL。默认值为 `15000` 毫秒。
    
    
    auth_cache.cached_backend = ldap  
    
    
    auth_cache.cache_ttl = 5000  
    

默认情况下，否定（拒绝）的身份验证和/或授权决策不会被缓存，仅缓存肯定的决策。但是，可以通过将 `cache_refusals` 设置为 `true` 来更改此行为，如下所示：
    
    
    auth_cache.cache_refusals = true  
    

## 高级缓存配置

您还可以使用自定义缓存模块来存储缓存请求。该模块应为一个实现 `rabbit_auth_cache` 行为的 Erlang 模块，并（可选地）定义 `start_link` 函数以启动缓存进程。

此存储库提供了几种实现：

  * `rabbit_auth_cache_dict` 将缓存条目存储在内部进程字典中。此模块仅用于演示，不应在生产环境中使用。
  * `rabbit_auth_cache_ets` 将缓存条目存储在 ETS 表中，并使用定时器进行缓存失效。**这是默认实现** 。
  * `rabbit_auth_cache_ets_segmented` 将缓存条目存储在多个 ETS 表中，不会删除单个缓存条目，而是使用单独的进程进行垃圾回收。
  * `rabbit_auth_cache_ets_segmented_stateless` 与上述相同，但最大限度地减少了 `gen_server` 状态的使用，利用 ETS 表存储关于分段的信息。



要指定缓存模块，请使用 `cache_module` 配置键。此示例配置使用了 `rabbit_auth_backend_ets_segmented` 模块。
    
    
    auth_cache.cache_module = rabbit_auth_backend_ets_segmented  
    

使用自定义 `cache_module` 实现时，可以通过 `cache_module_args` 指定 `start args`。`Start args` 应为传递给模块 `start_link` 函数的参数列表。

但是，额外的缓存模块参数只能通过 advanced.config 进行定义。
    
    
    [  
    
    
     {rabbit, [  
    
    
       %% ...  
    
    
     ]},  
    
    
      
    
    
     {rabbitmq_auth_backend_cache, [  
    
    
        {cache_module, rabbit_auth_backend_ets_segmented},  
    
    
        {cache_module_args, [10000]}  
    
    
      ]}  
    
    
    ].  
    

## 如何清除缓存

可以使用 `rabbitmqctl` 命令 `clear_auth_backend_cache` 清除所有集群节点上的缓存。
    
    
    rabbitmqctl clear_auth_backend_cache
